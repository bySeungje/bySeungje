## 지승제 (Seungje Ji)

**금융 도메인 전문 백엔드 시니어 | AML · MyData · 결제정산**

11년차 Java/Spring 백엔드 개발자. AML, MyData, 결제정산 도메인을 동시에 경험한 시장 희소 인력(1.5-3%).
대규모 금융·공공 시스템에서 **CTO 2회 · PM 2회 · PL 1회**. 한전 3회 지명, 우체국금융 2회 직접 호출 — **"지명받는 개발자"**.

| Achievement | Impact |

| AML 76개 STR 룰 DAG 재설계 — 병렬화 가능 룰 분리 | **배치 64% 단축** |
